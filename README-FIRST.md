# ZION — A moment. Made yours.

Extract the ZIP, then open **OPEN-WEBSITE.html** in Chrome, Edge, Safari or Firefox. This portable preview includes its images, fonts, styling and scripts in one file. No installation or server is required. An internet connection is needed only for Facebook and email links.

## Included

- Responsive editorial design in dark ink, copper and ivory.
- Six photographs selected from ZION's actual public event album.
- Portfolio filters, full-screen photography and saved inspiration.
- Event occasion, services, palette, guest count, venue and notes.
- A prepared inquiry to review, copy, download or open in an email app.
- FAQ, official Facebook links and the verified public business email.

## Editable source

Edit `index.html` for page content, `styles.css` for design and `app.js` for interactions. Keep `assets` beside these files when using the editable version. `asset-sources.json` records the original photography sources, `RESEARCH.md` explains factual decisions, and `licenses` contains the bundled fonts' licences.

After editing the source, run `python build-preview.py` to rebuild the portable preview. Source files are also ready for a static web host. No public deployment has been made.

The form prepares a message on the visitor's device. Nothing is sent automatically and no reservation or payment system is connected. Saved inspiration uses browser storage when available. Copying can fall back to manual selection if browser permissions prevent clipboard access.

## Owner review before launch

Confirm brand assets, photo permissions, current contact information, menus, service inclusions, rates and booking terms with ZION. This is an independent concept, not a claim of business endorsement. Past event photography does not guarantee that every pictured item or venue is included in a new proposal.
